# Repository Instructions

This repository uses `docs/PRD.md` as the product source of truth.

Before making any product, behavior, UI, workflow, data-contract, configuration, model, scraping, rendering, or publishing change:

1. Read `docs/PRD.md`.
2. Update `docs/PRD.md` in the same commit when the change affects the product.
3. If the PRD is not updated, state clearly in the final response or commit/PR notes why the change has no product impact.

Generated daily content under `output/` does not require a PRD update unless the generation rules, layout, data schema, source strategy, or publishing behavior changed.
